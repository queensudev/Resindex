Archive importer — 2025–26

Owner-use-only tool. Not linked from the main site. Writes exclusively to the archive_2025_26 collection — it never touches this year's sightings collection.

Before using this: temporarily set the archive_2025_26 rule in Firestore to allow create: if request.auth != null;, run your import, then change it back to allow write: if false; afterward. See SETUP.md for the exact rule text.

Format: one entry per line, separated by |:

Residence | Room Type | Beds Remaining | Date (YYYY-MM-DD) | Time (HH:MM, 24h) | Note (optional)

Room type must exactly match one of the building's real types, or use Any (total) if you only have an overall number. Example:

Chown Hall | Double | 5 | 2025-07-23 | 14:30 | only doubles left
